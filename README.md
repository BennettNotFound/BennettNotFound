## About

Hi, I'm HashCat Shigure.

I write tools, take software apart, and spend too much time on problems that were supposed to be trivial.

I like things that are fast, predictable, and actually work. Three requirements. Somehow that's asking a lot.

If something behaves strangely, I'd rather find the reason than call it *probably fine*.
